# valley-crown-play
Current Valley Crown game on GitHub Pages. Source and historical archives remain in penny323mo/valley-crown.

The stable link always opens the current build. For each new release, update
`release.json` and `previous-release.json` in the same commit, moving the
current public manifest into the previous slot. Both versioned directories are
published from their hash-verified archives. A retained older build is not a
save migration; the game still enforces its own checkpoint compatibility.
